# Brain Firmwares

This is a collection of firmwares for the [Brain module](https://github.com/shmoergh/moduleur/tree/main/modules/07-brain), released as part of the [Shmoergh Moduleur](https://www.shmoergh.com/moduleur/).

## Essentials
- [Le Controlleur](https://github.com/shmoergh/le-controlleur) — MIDI to CV converter and probabilistic sequencer. Your starter program for the Moduleur
- [CV utilities](https://github.com/shmoergh/brain-cv-utils) — 6 CV utilities packed in a single program.
- [LFO](https://github.com/mrmattallison/brain-programs/tree/master/lfo) — Sine, triangle, sawtooth, square, stepped random, smooth random low frequency oscillators. By [Matt Allison](https://github.com/mrmattallison)
- [Lo-Fi Delay](https://github.com/shmoergh/lo-fi-delay) — Mono digital delay (Pico2 only)

## Utilities
- [CV Tuner](https://github.com/shmoergh/brain-cv-tuner) — Control voltate software calibration tool for precise 1V/oct tracking. Persists calibration values across Brain SDK firmwares
- [Diagnostics Tool](https://github.com/shmoergh/brain-diagnostics) — Tools to test the hardware of the Brain module. Useful if you're building the module yourself and you want to make sure everything works as expected.
- [Output Tuner](https://github.com/shmoergh/brain-output-tuner) — Tool for DIY builders to help tune the base voltage of CV outputs on the Brain hardware.

## Deprecated

- [MIDI2CV converter](https://github.com/shmoergh/brain-basic-midi2cv) — Single channel MIDI to CV converter. Deprecated in favor of Le Controlleur.
